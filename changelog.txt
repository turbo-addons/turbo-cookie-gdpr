== Changelog ==

= 1.0.0 - 2026-08-09 =
* Initial release.
* Cookie consent banner with 5 position options (bottom, top, bottom-left, bottom-right, center modal).
* Preferences modal with 4 cookie categories: Essential, Functional, Analytics, Marketing.
* Script blocking for 40+ known tracking services (Google Analytics, GTM, Facebook Pixel, YouTube iframes, etc.).
* Google Consent Mode v2 integration — all 7 consent parameters supported.
* Consent logging with IP masking, stored in local WordPress database.
* Admin dashboard with consent statistics (30-day window).
* Banner customizer with color picker for all UI elements.
* Cookie categories manager — editable names and descriptions.
* Onboarding wizard (3 steps, activates on first install).
* CSV export for consent logs.
* Shortcode [turbo_cookie_preferences] for re-consent button.
* JavaScript API: window.TurboCookie.openPreferences().
* REST API endpoint for frontend consent logging (POST turbo-cookie/v1/consent).
* Configurable consent expiry, retention period, and consent versioning.
* Opt-in "Powered by Turbo Cookie" credit link (off by default).
* Privacy notice in admin dashboard.
* WordPress coding standards throughout.
* Compatible with WordPress 6.0+ and PHP 7.4+.
